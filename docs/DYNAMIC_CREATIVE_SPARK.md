## Product behavior and limits

Discovery, development and recommendation are distinct. A new article or retrieval date is not a new activity, and an editorial reference is not proof of growing demand. Spark now researches complementary sources and consolidates a small set of bilingual **opportunity briefs**. A brief asks a practical creative question, keeps its actual provenance and explicitly requires original activity development. It is not mislabeled a complete workshop.

The original eighteen curated identities remain available. Eight additional original offline explorations introduce meaningful water-transfer, ramp-motion, quiet-rhythm, color-overlay, cooperative building, rule-switching, fabric-texture and process-printing mechanisms. Their sensory, investigative and play mechanics differ from paper projects. These are suggested starting points, with bilingual preparation, safety, cleanup and accessibility notes; ages and durations remain editable suggestions, not adopted offerings. Existing three hosted research-informed versions and saved/refined history are never rewritten or removed.

The fallback is deliberately finite. **Unattended model-powered original development is implemented behind the existing authorization/binding/model/budget gates, but remains disabled and unverified with a real model.** Non-billable discovery and research briefs function without it. The software does not promise a genuinely new full workshop every day while inference is disabled. It also stops attaching different NASA links to the same four outlines and calling the result new inspiration. Interactive ChatGPT creativity and future authorized backend development can add genuinely different proposals to the same catalog.

- `spark.ts`, `spark_catalog`, `spark_runs`, profiles, preferences, seen/daily selection and draft records remain authoritative.
- `spark-sources.ts` provides three fixed adapters with independent polling/cache/error boundaries. No administrator/model-supplied fetch URL or scraping proxy exists.

- `spark-novelty.ts` compares actual participant actions, materials and experience, with mechanism recognition and deterministic weighted overlap. It does not use source URL, article title or a different seasonal story as novelty.
- `spark-experiences.ts` supplies the eight broader original offline starting points. It is a fallback vocabulary, not a claim of unlimited autonomous creativity.

No new table, framework, scheduler, provider SDK or parallel workshop/idea database is introduced. Source run summaries retain bounded provenance; immutable catalog versions retain the references used by developed/saved ideas. Source cache reads are limited to recent runs. Bounded maintenance removes at most ten completed/failed discovery records older than ninety days per tick. It never removes generation reservations or saved catalog provenance.

## Cadence and failure handling

The existing quarter-hour Worker trigger retains critical reconciliation/refund/outbox priority. Spark maintenance remains separate. Default new configuration supports **twice-daily discovery**, using Chicago AM/PM slots; daily, weekly and fortnightly choices remain available. An explicitly saved older frequency is respected. Daily recommendation identity uses `America/Chicago`, including DST, independently of UI locale. A repeated fall-back hour cannot create a second slot.

Each source has a unique twelve-hour lease key in the existing run table, at most three attempts and an hour between failure retries. A manual owner refresh respects the same source cache and the existing three-per-person/day limit. At most five external requests are needed across the three current adapters: NASA, LOC, one Met search and two Met records. Fetches reject redirects, use a 4.5-second timeout and a 512 KB body cap; source hosts/paths are fixed. RSS entities/DOCTYPE, off-host links, unreasonable dates and unsuitable record types are rejected. Individual source failures are isolated; useful cached references remain available for seven days. A partial run is recorded as partial/failed with sanitized codes, not disguised as all sources succeeding.

Cached/original/saved ideas remain usable on total outage. A run can legitimately add zero full ideas. When model development is later authorized, a stable opportunity ID prevents repeatedly charging for the same reference on manual refresh. One bounded opportunity is considered per run. Ambiguous/failed model execution is not automatically retried.

## Evidence and novelty

The interface distinguishes original exploration, research-inspired activity, seasonal opportunity and adaptation. A verified emerging trend would require a real permitted measurement source, dated comparison period and appropriate geographic qualification. **No current adapter measures interest, so verified-trend claims remain disabled.** Neither article wording, a model assertion, a source confidence number nor a current retrieval date can upgrade this evidence.

Novelty checks examine mechanism, participant actions, material roles and the underlying experience. Same-family candidates are duplicates; near-identical action/material combinations remain similar across different publishers, titles and seasonal framing. Comparison uses deterministic mechanism recognition and weighted lexical overlap, not an unverified semantic model. It catches the reported repeated paper-folding case but is not a guarantee against every paraphrase or a copyright/safety certification.

Scheduled model output is rejected when insufficiently novel; its conservative reservation remains. Exact content hashes still deduplicate immutable content. A deliberately reviewed interactive near-variation can be saved as an adaptation with its parent preserved. Old saved variations remain retrievable. AI family identity is derived from activity actions/materials instead of assigning every idea with the same tags to one family.

Recommendation heuristics balance practical materials, accessibility alternatives, underrepresented topics/mechanisms, genuinely dated context, season, explicit non-sensitive preferences and existing workshop themes. Seasonal weights are reduced; repeated recent mechanisms are penalized. Excellent evergreen ideas receive no arbitrary age penalty. These are editorial heuristics, not measured demand or customer satisfaction scores. No individual registration, guardian or child record is read for this process.
