## Discover → Evaluate → Develop → Recommend → Owner Review

The October 30 local continuation supersedes the NASA-only, fixed-outline discovery strategy and adds broader original fallbacks, independent complementary sources, qualified research briefs, mechanism-based novelty and reviewed interactive idea intake. [The current architecture and activation limits](DYNAMIC_CREATIVE_SPARK.md) distinguish this local candidate from the unchanged hosted version and from actual model execution. Historical implementation detail below remains an evidence record; it does not describe a newly deployed engine.

The shared `src/lib/spark.ts` service serves both administration and MCP. There is one idea catalog, not a separate assistant database.

1. **Discover:** bounded requests to NASA's official RSS endpoint; metadata only, without full article scraping, third-party instructions or photographs. Store source URL, publisher date, retrieval date and `topic-context` evidence. Seasonal context includes a calendar reference and the calculated fourth Thursday in November; it does not schedule a business event.
2. **Evaluate:** accept HTTPS source links only on fixed NASA hosts; reject redirects, oversized bodies, unexpected feed formats, XML entities, unsupported links and unsuitable dates. Topic matching selects relevant discovery context. Generated candidates must pass strict field lengths, bilingual structures, accepted topics/months, age/duration/complexity constraints and conservative safety screening.
3. **Develop:** without a model, use original Adventure Station outlines adapted to retrieved discovery topics. These are labeled **research-informed**, not AI-generated or verified trends. A prepared provider interface can develop new bilingual concepts when separately authorized. Model output cannot supply sources, prices, demand statistics, publication state or extra fields. Existing 18 curated ideas remain available without credentials or a network connection.
4. **Recommend:** cache a staff member's daily idea using the **America/Chicago** business day. Rank seasonal/current/upcoming months, non-sensitive staff preferences, saved topics, materials and existing workshop themes. Recent IDs and concept families reduce repetition across variations. Dismissed ideas stay excluded; filtered empty states remain usable. No individual child/guardian records feed ranking or models; aggregate attendance is not currently used.
5. **Owner Review:** save, dismiss, restore, show another, refine, prepare an editable variation and create a bilingual workshop draft. Refinements append immutable catalog versions; content fingerprints include both languages and all creative fields, preserving Spanish-only edits. Saved/dismissed records survive refreshes, and older saved versions remain retrievable. No refresh, assistant or model publishes workshops, creates class dates, picks prices, approves venues or adopts policies.

Three new tables are retained: `spark_catalog` (immutable content/provenance versions), `spark_runs` (leases, attempts, outcomes and reserved usage), and `spark_profiles` (non-sensitive inspiration preferences). Existing preferences/daily/seen/draft tables are reused. There is no table per conceptual pipeline stage. The temporary migration snapshot table is removed before completion.

## Scheduling, failure handling and configuration

Reuse the existing 15-minute Worker trigger. Payment reconciliation, refunds and notification processing finish first and retain their existing completion marker. `ctx.waitUntil` runs creative maintenance separately. Weekly/fortnightly periods use the Chicago date across DST; a unique job key, 45-second lease, one-hour retry delay and maximum three attempts bound discovery. Daily selection is filled for up to five active, bound operational staff per tick. No owner button is needed for ordinary refreshes. The manual refresh action permits three requests per staff member per Chicago day.

RSS fetches use a five-second abort signal and a 512 KB limit; at most eight references and four developed candidates are processed per run. Cached/curated content remains available on source failure. Errors retain stable codes and run status, not raw provider responses or credentials. Repeated content is deduplicated rather than called newly popular or repeatedly replacing saved work. A research run may legitimately add zero ideas.

Owner/Godmin can configure research frequency, a registered provider, model identifier, generation preference and a monthly USD cap, and inspect reserved usage/request counts. Ordinary staff can configure their own topics, age range, complexity and materials. Secrets have no database or frontend field.

Model generation is **prepared, not activated**. The initial registered adapter is Cloudflare Workers AI; the engine uses a vendor-neutral `SparkProvider` contract. No model binding, AI key, subscription or inference is provisioned by this update. The disabled deployment settings are:

```
SPARK_AI_AUTHORIZED=false
SPARK_AI_MONTHLY_LIMIT_MICROUSD=0
SPARK_AI_REQUEST_LIMIT_MICROUSD=0
SPARK_AI_ALLOWED_MODELS=
```

Future activation requires an explicitly authorized native `SPARK_AI` binding/provider adapter, a verified supported model and pricing, a deployment model allowlist, positive global/per-request ceilings and a positive application cap. Saving UI preferences alone cannot activate it. The effective cap is bounded by deployment authorization; reservations are atomic across concurrent runs. Ambiguous/failed calls keep their reservation and are not automatically retried. An eight-second application deadline bounds generation waits. Usage is **reserved budget**, not a claim that a provider invoice or actual cost has been verified. Validate conservative request ceilings against current provider pricing before authorizing paid use.

Safety heuristics screen hazardous chemicals/mixtures, unsafe ingestion and unsupported guarantees, while distinguishing explicit prohibitions such as “No tasting.” Outputs require adult-supervision considerations. Provider safety/cleanup/accessibility lengths fit the existing workshop instruction field without silent removal. These checks are partial screening, not a safety certification or a substitute for staff reviewing materials, allergies, skin/eye sensitivity and activity suitability.
